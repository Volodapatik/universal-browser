# 🎬 Универсальный Браузер

Умный браузер с поиском и YouTube интеграцией.

## 🌟 Возможности

- 🔍 **Поиск в интернете** - через Google Custom Search API
- 📺 **YouTube интеграция** - поиск видео, каналов, стримов
- 👤 **Система аккаунтов** - регистрация и вход
- 💾 **Сохранение данных** - история просмотров и подписки
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🚀 Быстрый старт

1. Перейдите на [GitHub Pages сайт](https://your-username.github.io/universal-browser)
2. Начните поиск или перейдите в режим YouTube
3. Зарегистрируйтесь для сохранения истории и подписок
